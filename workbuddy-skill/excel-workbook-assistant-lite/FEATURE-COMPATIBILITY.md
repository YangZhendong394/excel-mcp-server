# Excel MCP Server 原版功能对照表（轻量版）

**对照对象：** 本仓库基于上游 Excel MCP Server 2.2.6 的 WorkBuddy 轻量版原型。  
**原版工具口径：** 默认配置 46 个工具；另外 2 个 VBA 写入/删除工具需显式开启 --allow-vba-write，不计入默认 46 个。  
**轻量版当前版本：** 2.0.0-alpha.1。此表按当前代码与已执行测试记录，不把“对象能被动保留”算作“具备编辑该对象的功能”。

## 状态说明

- **部分保留**：有相近命令，但参数、范围或行为明显少于原版工具。
- **未保留**：轻量版没有对应功能入口。
- **待验证**：实现路径存在合理的保留机制，但尚无足够测试证据。
- **被动保留**：修改其他单元格时对象可能随工作簿保存而保留；不代表可创建、编辑、删除或完整无损。

## 已验证的“被动保留”范围

以下项目已在自动化样本中通过写入无关单元格后的保留检查：常见字体/填充/对齐/边框、数字格式、合并单元格、冻结窗格、工作表自动筛选、Excel 表格、公式表达式、超链接、批注、数据验证、标准条件格式、图表、行高列宽和隐藏工作表。

另外，WorkBuddy 本机真实样本已核实：公式、数据验证、表格、图表、合并区域、冻结窗格和常见格式保留；样本中的 x14 渐变数据条被标准化成标准实心数据条，渐变扩展属性丢失，但人工打开后肉眼观感基本一致。

**宏保留正在单独验收。** 只有“原有 VBA 二进制部件在另存副本后逐字节一致”通过后，才会标记为被动保留；这仍不表示支持读取/编辑 VBA，也不表示宏执行正确。

## 尚未证明可无损保留或明确不支持的对象

数据透视表、切片器/时间线、迷你图、形状、表单控件、嵌入对象、特殊图表扩展、链接数据类型、数字签名和自定义 XML 等，不因轻量版通过常规工作簿测试就获得无损保证。处理包含这些对象的文件前，应提示用户先备份，并对测试副本进行专门验证。

## 发布前必须完成的验收

1. 公式表达式与缓存值行为：确认公式不被误当成计算结果，缓存缺失/过期时如实提示。
2. xlsm 被动保留：在真实带宏工作簿中修改普通单元格，逐字节比对 xl/vbaProject.bin，原文件不得改变；不得执行宏。
3. 异常文件保护：损坏的 ZIP/XLSX 必须安全报错，不留下半成品或覆盖原文件。
4. 用户指令边界：确认模型不会把“未实现”的功能描述成已支持。
5. 完成本表逐项复核后，才决定是否从 alpha 进入正式发布版本。
